# OPERATIONAL-GOVERNANCE Ownership

This internal domain owns reusable procedures, runbooks, cadences, register
shapes, control patterns, and evidence definitions under this directory.

It consumes ratified FRAMEWORK-DEFINITION material read-only. It does not own
framework policy, live portfolio or project state, adopter evidence, Agent
Workflow records, Fusion Harness execution, or human authority.

Real assignments, execution state, and durable evidence remain in the
independent repository or coordination system that owns them. See the
[scope constitution](constitution.md) and
[framework ownership](../framework/ownership.md).
