# FRAMEWORK-DEFINITION Ownership

This internal domain owns reusable principles, policy, standards, decision
rights, framework specifications, grounding guidance, and canonical
repository-owned framework skills under this directory.

It consumes GLOBAL authority and grounded sources. It does not own operational
procedures, live controls, adopter architecture, project state, evidence,
integrations, or execution.

OPERATIONAL-GOVERNANCE may consume ratified framework definitions through a
one-way dependency. Reverse dependence on live operational state is prohibited.
See the [scope constitution](constitution.md) and
[operations ownership](../operations/ownership.md).
